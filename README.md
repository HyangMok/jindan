# 우리동네 정비진단 (jindan)

주민이 정비사업 필수요건을 시·도 조례 기준으로 직접 확인하는 공공 서비스 모델 — 제8회 공간정보 활용·아이디어 경진대회 출품(분야 ② 공간정보 활용모델, 개인 참가 황순필).

- **데모(웹 지도)**: https://__GH_USER__.github.io/jindan/  — 상계동 154-3일대(서울특별시고시 제2025-218호) 건물별 노후 판정·준공 연대·과소필지(건축물대장 표제부 조인 후). 원자료 재배포를 피하기 위해 건물·필지는 중심점으로만 표시합니다
- **재현 코드**: `code/` (판정 엔진·기준표 자동 생성·검증 스크립트), 실행 순서는 `code/README.md`
- **원자료 캐시는 포함하지 않습니다.** 브이월드·공공데이터포털 이용약관에 따라 API로 받은 건물·필지·표제부 원자료는 재배포하지 않으며, `code/collect_cache.py`(브이월드 키)와 `code/join_ledger.py`(건축HUB 키)로 누구나 같은 캐시를 다시 만들 수 있습니다(13개 구역, API 약 300회 + 표제부 약 1,100회)
- **검증 결과**: `data/*.json` — 기준표 자동 생성 대조, 강건성, 교차 판정, 접도율(폭 반영), 호수밀도 특례 근사, 충족 시점, 유형 매트릭스, 표제부 조인, 경계 사례, 경기 실지
- **진단서 샘플**: `reports/` (10개 기지정 구역, 자동 생성 PDF)
- **실증 기록**: `docs/실증_다구역검증_v1.md` (v1~v12), `docs/판정기준_서울시조례_v1.md`

## 사용 데이터 (전부 무상 개방)
브이월드 오픈API(건축물정보·연속지적도 WFS, 용도지역, 지오코더, WMTS), 국가법령정보센터 API(서울·경기 조례, 도시정비법 시행령 별표1, 소규모주택정비법 시행령), 서울 열린데이터광장 의제처리구역 위치정보(OA-20957), 공공데이터포털 건축HUB 건축물대장 표제부.

## 재현
```bash
pip install pyshp pyproj shapely scikit-learn pypdf pymupdf pillow
cp code/.env.example code/.env   # VWORLD_KEY(브이월드), BLDG_KEY(공공데이터포털 건축HUB), LAW_OC(국가법령정보 오픈API ID) — 모두 무료 발급
cd code
python collect_cache.py    # 13개 구역 건물·필지 캐시 생성 (VWORLD_KEY) — 아래 스크립트의 입력
python rules_from_law.py   # 조례 별표·조문 → 기준표 (서울·경기, 수동표와 52케이스 대조)
python robustness.py       # 경계 강건성·교차 판정 (캐시 기반)
python road_width.py       # 접도율(도로 폭 반영)
python timing.py           # 충족 예상 시점
python types.py            # 유형별 판정 매트릭스 + 가로구역 자동 생성
python join_ledger.py 상계동   # 표제부 조인 (BLDG_KEY)
python report.py <results.json>  # 진단서 PDF (headless Chrome 필요)
```
데모 지도는 `index.html` 하나로 동작합니다. 배경지도는 기본 OpenStreetMap이며, 브이월드 WMTS를 쓰려면 해당 도메인에 등록한 키를 `?vworld=<키>`로 붙여 엽니다(키가 포함된 주소는 공유하지 마십시오). 로컬에서 폴리곤 버전을 보려면 캐시 생성 후 `build_demo.py`를 실행합니다.

## 판정 범위 고지
본 도구는 조례 별표1 연한 기준의 노후도·면적·과소필지와 근사 지표(접도율·호수밀도)만 판정합니다. 불량건축물(도시정비법 제2조3호 가~다목)·재건축진단·주민동의·기본계획 적합성은 판정하지 않으며, 결과는 정비구역 지정을 보장하지 않습니다. 이용자 지정 경계에 대한 결과는 "필수요건 범위 내(공식 검토 필요)"로만 표기합니다.
