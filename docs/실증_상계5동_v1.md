## 실증 대상

- **상계5동 주택정비형 재개발구역** (서울 노원구 상계동 154-3 일대)
- 구역 면적 216,364.5㎡(21.6ha), 정비구역 지정 고시 **2025-04-17**, 계획 4,591세대
- 선정 사유: 기지정·공개 고시 구역(신청서 공개 시 보안 문제 없음), 노후 저층 주거지(공공 프레임 부합), 조례 제6조 전 지표가 적용되는 재개발 유형, 진행 업무 구역과 무관

## 실행 파이프라인 (전 구간 브이월드 API 실호출)

1. 지오코더 API: "노원구 상계동 154-3" → (127.07083, 37.66382) 변환 성공
2. WFS `lt_c_bldginfo`: 구역 일대 근사 범위(약 555m×565m, 3×3 타일 분할 수집 — MAXFEATURES 1000 제한 대응) → **1,172동** 수집
3. WFS `lp_pa_cbnd_bubun`: 동일 범위 **1,301필지** 수집, 등장방형 근사로 필지면적 산출
4. 조례 제4조·별표1 로직으로 건물별 노후 판정 (구조코드 RC계열/기타, 용도 공동주택 여부, 준공년도별 연한)
