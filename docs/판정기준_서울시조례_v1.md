## 2. 정비계획 입안대상지역 요건 (조례 제6조 ①)

**공통 지표 정의 (제2조)**
- **과소필지**(제9호): 토지면적 **90㎡ 미만**
- **주택접도율**(제10호): 폭 **4m 이상** 도로에 길이 **4m 이상** 접한 대지의 건축물 수 ÷ 구역 내 건축물 총수 (연장 35m 이상 막다른 도로는 폭 6m 기준)
- **호수밀도**(제5호): 구역 1ha당 건축물 동수. 산정 특례 — 공동·다가구주택은 최다 세대층의 1세대=1동, 신발생무허가 제외, 존치 공원·학교 면적 제외, 비주거용은 건축면적 90㎡당 1동

**유형별 요건**

| 구역 유형 | 필수 요건 | 선택 요건 (하나 이상) |
|---|---|---|
| 주거환경개선구역 | 호수밀도 ≥ 80 | 노후도(동수) ≥ 60% / 접도율 ≤ 20% / 과소필지 ≥ 50% |
| 주택정비형 재개발구역 | 면적 ≥ 1만㎡(재정비촉진지구 심의 시 5천㎡) **및** 노후도(동수) ≥ 60% | 과소필지 ≥ 40% / 접도율 ≤ 40%(도로폭 6m 기준) / 호수밀도 ≥ 60 |
| 도시정비형 재개발(역세권) | 승강장 경계 반경 500m 이내 **및** 노후도(동수) ≥ 60% | (제외: 전용주거·공원·자연경관지구·최고고도지구 접한 지역, 중점경관관리구역 등) |
| 재건축(주택단지 외 포함, ⑥항) | 영 별표1 제3호라목 면적 = **1만㎡ 이상** | — |

- 제6조③: 부지 정형화 등 필요시 도시계획위 심의로 입안대상 면적의 120%까지 입안 가능.

## 3. 브이월드 데이터 매핑 (판정 엔진 입력)

| 판정 지표 | 필요 속성 | 데이터 소스 | 수급 상태 |
|---|---|---|---|
| 노후도 | 사용승인일 `useapr_day`, 구조 `strct_cd`, 용도 `usability`, 층수 `grnd_flr` | `lt_c_bldginfo` (WFS) | **실호출 확인** |
| 과소필지(90㎡) | 필지 면적(지오메트리 산출) | `LP_PA_CBND` 연속지적도 | 제공 확인 |
| 구역 면적 | 구역 경계 | 사용자 입력/지적 집계 | — |
| 접도율 | 도로 폭·접도 길이 | 지적 도로필지 + 도로명주소 도로구간 기하 연산 | **부분** — 도로 폭 산정은 기하 근사, 한계 명시 필요 |
| 호수밀도 | 동수(산정 특례 반영) | `lt_c_bldginfo` 동 단위 + 건축물대장 API(세대수 보정) | 근사 가능, 정밀화엔 건축물대장 병용 |
| 역세권 500m | 역 승강장 위치 | 브이월드 검색 API/철도역 레이어 | 제공 확인 |
| 용적률 상한 | 용도지역 | `LT_C_UQ111` 계열 + 도시계획조례 | 제공 확인 |

**시사점**: 노후도(핵심 요건)는 브이월드 단독으로 완전 판정 가능. 접도율·호수밀도는 근사 판정 후 "정밀 판정은 실태조사 필요" 단서를 진단서에 표기하는 구조가 정직하고, 심사 대응(정확성)에도 유리.

## 4. 판정 엔진 의사코드

```
for 건물 in 구역내_건물(lt_c_bldginfo):
    연한 = lookup(구조=strct_cd, 용도=usability, 층수=grnd_flr, 준공년도=useapr_day[:4])  # 제4조+별표1
    건물.노후 = (기준일.년 - 준공년도) >= 연한
노후도 = count(노후건물) / count(전체건물)          # 동수 기준
과소필지율 = count(필지면적 < 90) / count(전체필지)   # 제2조제9호
접도율 = count(접도조건 충족 대지의 건물) / count(전체건물)  # 제2조제10호(근사)
호수밀도 = 동수(특례반영) / 구역면적_ha              # 제2조제5호(근사)
판정 = match(제6조 유형별 요건표)                    # 요건별 충족/미충족 + 근거조문 출력
```
